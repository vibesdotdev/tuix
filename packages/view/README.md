# @tuix/view

View primitives, layouts, and caching for terminal UI rendering.

## Status

🚧 **Under Construction** - This package is being created as part of the @tuix/core split refactoring (Phase 5).

## Purpose

Provides the view layer for TUIX applications:

- **View Primitives** - Core view types and rendering functions
- **Layout System** - Flexbox, grid, box, spacer utilities
- **View Caching** - LRU-based caching for performance
- **String Utilities** - Width calculations, wrapping, alignment

## Installation

```bash
bun add @tuix/view
```
